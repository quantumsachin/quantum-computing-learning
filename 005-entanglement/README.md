## Bell State

The first argument to CNOT is the control qubit and the second argument is the target qubit.


To Create Phi Minus Bell state: apply Z operation
Similarly to create Psi Plus and Psi Minus Bell state: apply X and Z operations


To create the Bell state Psi Plus, apply the Pauli gate to the target qubit after you apply the Hadamard gate to the control qubit. Then apply the CNOT gate

To create the Bell state Psi Minus, apply the Pauli to the control qubit and the Pauli to the target qubit after you apply the Hadamard gate to the control qubit. Then apply the CNOT gate.
